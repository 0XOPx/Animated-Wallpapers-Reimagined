---

## Reporting a Vulnerability

We take the security and integrity of our native binary engines seriously. If you discover a security vulnerability or unexpected memory safety exploitation vectors within **Animated Wallpapers Reimagined**, please do not open a public issue. 

Instead, report vulnerabilities directly to the maintainer via the official security contact channel:

* **Contact/Project Lead:** OXOP
* **Reporting Method:** Please open a confidential report or contact the creator via their verified developer profile networks.

### What to Include in Your Report
To help us triage and patch the issue quickly, please include:
1. A clear description of the vulnerability or memory allocation bug.
2. A minimal reproducible example (PoC code, crash dump log, or step-by-step instructions).
3. The specific toolchain (GCC or Clang) and target Windows version where the issue was observed.

### Our Process
* **Acknowledgement:** You will receive an initial response acknowledging your report within 48 hours.
* **Triage & Patching:** The issue will be analyzed privately, and a fix will be engineered directly in the mainline source.
* **Disclosure:** Once a patch is released, a security advisory will be published to credit the researcher, unless an anonymous disclosure is requested.
